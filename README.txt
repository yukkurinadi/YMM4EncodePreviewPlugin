========================================================================
 YMM4 動画出力プレビュープラグイン (YMM4EncodePreviewPlugin)
========================================================================

ゆっくりMovieMaker4 (YMM4) で動画出力（レンダリング・エンコード）が
開始された際に、出力しきっている最新の1フレームをリアルタイムで
プレビュー表示するプラグインです。

------------------------------------------------------------------------
制作者・プラグイン案
------------------------------------------------------------------------

▶制作者:[ゆっくりなぢ](https://x.com/yukkurinadi)

------------------------------------------------------------------------
■ 主な機能・特徴
------------------------------------------------------------------------

1. Lib.Harmony による内部パイプラインのリアルタイムフック
   - YMM4の内部パイプライン（VideoFileWriter）を動的フック。
   - レンダリング完了直後の Direct2D サーフェスから最新の1フレーム
     バッファを低オーバーヘッドで直接抽出します。

2. 独立 STA スレッドによるモーダル完全回避
   - 動画出力中に YMM4 のメインUIスレッドが無応答・モーダル状態に
     なっても影響を受けないよう、完全に独立した専用 STA スレッド上で
     プレビューウィンドウを生成・表示。
   - エンコード開始と同時に自動でポップアップし、滑らかに約60fpsで
     描画更新されます。

3. アスペクト比の自動完全フィット（隙間ゼロ）
   - 動画の解像度（16:9 や 縦動画 9:16、4:3 等）から最適なサイズを
     自動計算。
   - ウィンドウの左右・上下に余白や黒帯（隙間）が一切生じない
     ぴったりフィット表示。
   - 誤操作による比率崩れを防ぐサイズ固定仕様。

4. 透過動画 / 通常動画の背景自動切り替え
   - 透過対応フォーマット（PNG連番 / 透過動画等）：
     市松模様（チェッカーボード）で透明領域を透過表示。
   - 通常の MP4 等（非透過）：
     YMM4のプロジェクト設定に応じた背景色（または黒）で塗りつぶし、
     実際の完成動画と同じ見た目でプレビュー。

5. 自動ライフサイクル管理
   - 出力開始時：VideoFileWriter 生成の瞬間に自動で先行オープン。
   - 出力完了時：エンコード完了（またはキャンセル）時に自動でクローズ。

------------------------------------------------------------------------
■ 動作環境
------------------------------------------------------------------------

- OS: Windows 10 / 11 (64bit)
- 対象アプリケーション: ゆっくりMovieMaker4 (v4.50 以降 / .NET 10 対応)
- フレームワーク: .NET 10.0-windows / WPF

------------------------------------------------------------------------
■ インストール方法
------------------------------------------------------------------------

【自動インストール (推奨)】
PowerShell を開き、本フォルダで以下のコマンドを実行します。
  .\install.ps1

※ 自動的に C:\YMM4\user\plugin\EncodePreviewPlugin などを検知して
   ファイルを配置します。

【手動インストール】
1. bin\Release\net10.0-windows\ 内の以下のファイルをコピーします：
   - EncodePreviewPlugin.dll
   - EncodePreviewPlugin.deps.json
   - 0Harmony.dll
2. YMM4 のプラグインフォルダに EncodePreviewPlugin フォルダを作成し、
   上記ファイルを配置します：
   例: C:\YMM4\user\plugin\EncodePreviewPlugin\

------------------------------------------------------------------------
■ ビルド方法
------------------------------------------------------------------------

.NET 10 SDK がインストールされている環境で以下を実行します：
  dotnet build -c Release

ビルド成果物は bin\Release\net10.0-windows\ に出力されます。
