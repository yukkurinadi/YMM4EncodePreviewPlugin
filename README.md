# YMM4 動画出力プレビュープラグイン (YMM4EncodePreviewPlugin)

ゆっくりMovieMaker4 (YMM4) で動画出力（レンダリング・エンコード）が
開始された際に、出力しきっている最新の1フレームをリアルタイムで
プレビュー表示するプラグインです。

## 主な機能・特徴

1. **エンコード開始を自動検知**  
   動画出力を開始するとウィンドウが自動で開きます。

2. **エンコード済みのフレームを表示**  
   いまどこまでエンコードし終わっているのかが視覚的にリアルタイムでわかります。

3. **出力を一時停止 / 再開**  
   プレビュー画面からエンコード処理を一時停止・再開できます。PCの負荷を一時的に抑えたいときなどに便利です。

4. **出力をここで停止（途中保存）**  
   現在エンコードが完了しているフレームまでで動画出力を切り上げ、正常な動画ファイルとして保存・完成させます（誤操作を防ぐ確認ダイアログ付き）。

5. **停止位置バーで出力位置を調整**  
   プレビュー画面の「停止位置」バーは出力の進行に合わせて自動で進みます。つまみをドラッグするとエンコードが一時停止し、出力済みの範囲内で停止位置を選べます。ドラッグ中は選んだ位置のフレームがプレビューに表示されます。つまみを離したあとも一時停止したままなので、「この位置で停止を確定」ボタンで確定してください。出力済みより手前を選んだ場合は、保存後に動画ファイルをその位置まで切り詰めます（ffmpegのストリームコピーを使用するため、再エンコードは行いません）。「再開」を押すと選択を解除して出力を続行します。

6. **エンコーダー設定項目への強制埋め込み（拡張出力機能）**  
   すべての動画出力エンコーダーの設定画面に以下の2つのトグル項目を自動的に埋め込みます：
   - **選択したアイテムだけ出力**: タイムラインで選択されているアイテムのみを描画（他のアイテムや背景を自動非表示）にし、出力時間範囲も選択アイテムに合わせて出力します。
   - **シークバーの位置から出力**: タイムライン上の現在のシークバー（再生ヘッド）の位置を開始フレームとして末尾まで出力します。

7. **自動終了**  
   動画出力が終わると自動でプレビューウィンドウが閉じます。

## インストール方法

【.ymme形式】
このGithubリポジトリのReleaseから最新版の.ymmeファイルをダウンロードして実行すると自動的にダウンロードされます。

【手動】
このGithubリポジトリのReleaseから最新版のzipをダウンロードして解答すると.dllファイルがあります。
.dllファイルをご自身のYMM4のフォルダ(ymm4/といいます)を開き、
ymm4/user/plugin/YMM4EncodePreviewPlugin/(先程のdll)
と置きます。
YMM4EncodePreviewPluginフォルダは作成してください。
